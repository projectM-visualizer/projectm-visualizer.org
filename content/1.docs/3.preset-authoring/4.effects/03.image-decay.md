---
title: Image Decay
description: Gradually darkens the image passed on to the next frame.
---

![Image Decay Effect](/content/preset-guide/effect-image-decay.png){style="width: 50%;"}

Darkens the whole "main" image with the given multiplication factor each frame immediately before applying
the [Image Warp effect](/docs/preset-authoring/effects/image-warp).

::note  
**Important**: This effect will only be applied if `MILKDROP_PRESET_VERSION` is set to 140 _or_ the `PSVERSION` (preset
version 200) or `PSVERSION_COMP` (preset version 201) values are set to a value below 2!
::

If a warp shader is used, the decay value has no effect and the warp shader must handle the decay on its own if
necessary.

## Default Settings

The following setting keys configure the default values and initialize expression variables for the Default Waveform
effect:

| .milk Setting Key | Type  | Range  | Description                                                                                                                           |
|-------------------|-------|--------|---------------------------------------------------------------------------------------------------------------------------------------|
| `fDecay`          | FLOAT | 0 .. 1 | The factor each pixel color value is multiplied with each frame.<br>(0 = clear image, 0.98 = default, slight darkening, 1 = no decay) |

## Expression Code Usage

The Image Decay effect can be controlled by using the `decay` variable in Milkdrop expression code in the following code
blocks:

- `per_frame_init_`
- `per_frame_`

| .milk Setting Key | Expression Variable | Writeable |
|-------------------|---------------------|-----------|
| `fDecay`          | `decay`             | YES       |
