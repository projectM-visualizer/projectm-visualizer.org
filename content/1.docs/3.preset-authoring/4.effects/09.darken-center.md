---
title: Darken Center
description: Darkens the very center of the screen.
---

![Darken Center Effect](/content/preset-guide/effect-darken-center.jpg){style="width: 50%;"}

The Darken Center effect draws a small, black and diamond-shaped area in the center of the screen. This can be useful to
reduce over-saturation in combination with warp and zoom effects.

This effect is not configurable other than enabling or disabling it.

## Default Settings

The following setting keys configure the default values and initialize expression variables for the Default Waveform
effect:

| .milk Setting Key | Type | Range  | Description                                   |
|-------------------|------|--------|-----------------------------------------------|
| `bDarkenCenter`   | BOOL | 0 or 1 | Enables or disables the Darken Center effect. |

## Expression Code Usage

This effect cannot be controlled with expressions.
