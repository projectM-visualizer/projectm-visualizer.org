![Default Waveform Effect](/content/preset-guide/effect-default-waveform.jpg){style="width: 50%;"}

This is the oldest and probably most often used effect in Milkdrop presets. It draws audio data as a waveform, using the
available PCM or spectrum data to achieve different effects for each of the avaiable waveform modes.

This effect can only be customized through a number of parameters, the actual shape of the waveform is hard-coded and
based on the selected waveform mode. To control each single point of a waveform,
the [Custom Waveform effect](custom-waves) must be used instead.

## Default Settings

The following setting keys configure the default values and initialize expression variables for the Default Waveform
effect:

| .milk Setting Key       | Type  | Range       | Description                                                                           |
|-------------------------|-------|-------------|---------------------------------------------------------------------------------------|
| `nWaveMode`             | INT   | 0 .. 7/8/15 | The drawing mode for the waveform. See below for supported modes and examples.        |
| `bAdditiveWaves`        | BOOL  | 0 or 1      | If non-zero, the waveform is drawn additive instead of replacing color in the image   |
| `bWaveDots`             | BOOL  | 0 or 1      | If non-zero, the waveform is drawn as dots instead of lines                           |
| `bWaveThick`            | BOOL  | 0 or 1      | If non-zero, the waveform is drawn four times in a 2x2 pattern to increase visibility |
| `bModWaveAlphaByVolume` | BOOL  | 0 or 1      | If non-zero, the waveform's alpha value is modulated by the audio volume              |
| `bMaximizeWaveColor`    | BOOL  | 0 or 1      | If non-zero, the color is brightened until one channel is saturated (1.0)             |
| `fWaveAlpha`            | FLOAT | 0 .. 1      | Determines the general opaqueness of the waveform. 0 disables the effect completely   |
| `fWaveScale`            | FLOAT | \>= 0       | The scaling factor for the waveform                                                   |
| `fWaveSmoothing`        | FLOAT | 0 .. 1      | The smoothing factor of the waveform. 0=no smoothing, 1=heavily rounded               |
| `fWaveParam`            | FLOAT | any         | A "mystery" parameter, affecting each waveform mode in a different way                |
| `fModWaveAlphaStart`    | FLOAT | 0 .. 1      | The minimum value for the volume-based alpha modulation                               |
| `fModWaveAlphaEnd`      | FLOAT | 0 .. 1      | The maximum value for the volume-based alpha modulation                               |
| `wave_r`                | FLOAT | 0 .. 1      | Default amount of red color in the wave                                               |
| `wave_g`                | FLOAT | 0 .. 1      | Default amount of green color in the wave                                             |
| `wave_b`                | FLOAT | 0 .. 1      | Default amount of blue color in the wave                                              |
| `wave_x`                | FLOAT | 0 .. 1      | Position of the waveform: 0 = far left edge of screen, 0.5 = center, 1 = far right    |
| `wave_y`                | FLOAT | 0 .. 1      | Position of the waveform: 0 = very bottom of screen, 0.5 = center, 1 = top            |

## Expression Code Usage

All settings of the Default Waveform effect can be controlled using Milkdrop expression code in the following code
blocks:

- `per_frame_init_`
- `per_frame_`

Most of the global default values as listed above can be used and changed in the `per_frame_init_` and `per_frame_`
blocks as follows:

| .milk Setting Key    | Expression Variable | Writeable |
|----------------------|---------------------|-----------|
| `nWaveMode`          | `wave_mode`         | YES       |
| `bAdditiveWaves`     | `wave_additive`     | YES       |
| `bWaveDots`          | `wave_usedots`      | YES       |
| `bWaveThick`         | `wave_thick`        | YES       |
| `bMaximizeWaveColor` | `wave_brighten`     | YES       |
| `fWaveParam`         | `wave_mystery`      | YES       |
| `wave_r`             | `wave_r`            | YES       |
| `wave_g`             | `wave_g`            | YES       |
| `wave_b`             | `wave_b`            | YES       |
| `fWaveAlpha`         | `wave_a`            | YES       |
| `wave_x`             | `wave_x`            | YES       |
| `wave_y`             | `wave_y`            | YES       |

### Notes

- The above values are not retained across frames.
- Each value will be set to the default value assigned in the .milk file at the start of each of the above code blocks.
- Any changes made to the variables in the `per_frame_init_` code are discarded and reset to defaults in the
  `per_frame_` block.

## Waveform Modes

Milkdrop supports eight waveform modes, with a ninth, experimental mode added in a later 2.x release. Some Milkdrop
forks and projectM support seven additional waveform modes, for a total of 16. In any case, the mode wraps around if it
is larger than the supported number of modes in Milkdrop and all known forks and reimplementations. This means that
presets using modes larger than 8 may look differently between renderers.

### Mode 0: Circle

![Default Waveform Effect](/content/preset-guide/default-waveform-mode-0.png){style="width: 30%; float:right;
margin: 1em;"}

A simple circle, with the left audio channel determining the radius of each point.

The wave parameter acts as a scaling value for the circle's radius (not to be confused with the wave scale parameter,
which scales the audio data).

<div style="clear:both"></div>

### Mode 1: X/Y Oscillation Spiral

![Default Waveform Effect](/content/preset-guide/default-waveform-mode-1.png){style="width: 30%; float:right;
margin: 1em;"}

A squashed, spiral-like wave that rotates around the waveform's center position.

The wave parameter acts as a scaling value for the overall circle radius (not to be confused with the wave scale
parameter, which scales the audio data).

<div style="clear:both"></div>

### Mode 2: Centered Spiro

![Default Waveform Effect](/content/preset-guide/default-waveform-mode-2.png){style="width: 30%; float:right;
margin: 1em;"}

A random-looking spiraling waveform than revolves around the waveform's center position.

The wave parameter has no effect on this mode.

<div style="clear:both"></div>
