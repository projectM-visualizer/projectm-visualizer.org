![Blur Texture Effect](/content/preset-guide/effect-blur-texture.png){style="width: 50%;"}

Creates several smaller, blurred variants of the "main" texture immediately after applying
the [Image Warp effect](image-warp).

The Blur Texture effect itself does not alter the preset image in any way, but updates additional textures available
in [preset shaders](../shaders).

## Using the Textures In Shaders

The resulting textures can be accessed from within both Warp and Composite shaders. Instead of using the `sampler_`
syntax, blur textures are exclusively accessed using these three special functions in shader code:

- `GetBlur1(uv)`
- `GetBlur2(uv)`
- `GetBlur3(uv)`

As with normal texture samplers, the sample coordinate `uv` is a `float2` vector, while each function returns the RGB
color as a `float3` vector.

Each functions returns a more heavily blurred (and smaller) image, with 1 being only slightly blurred, while 3 is
heavily blurred.

::note  
Blur textures are only created or updated if a shader actually uses them, e.g. calls any of the `GetBlurN()` functions.
Only the required blur levels are created depending on which of these functions are called. Thus, only call these
functions if the result is actually used in the resulting image!
::

### Color Clipping

Using the clipping values, the color range within the blur texture can be clipped to a smaller range, increasing the
color resolution and only keeping colors in a certain brightness range. Each blur level has its own clipping range, from
min to max. Color values (R, G and B are considered individually) below the minimum clipping value are raised to the
minimum value, and color above the maximum value are lowered to the maximum value.

Because each level has its own set of min/max value, care must be taken to not clamp all colors to a single value, e.g.
if the minimum value of blur level 1 is above the maximum level of blur level 2.

When using clipped blur textures in shaders, be aware that clipped color values are not rescaled to a \[0..1] range.
Especially with a minimum clipping value, it is probably necessary in most cases to subtract it from all components in
the sampled color value again before using the result, e.g.:

```hlsl
ret += (GetBlur1(uv) - blur1_min);
```

If not done properly, the resulting image will probably look washed out or the intended effect will not work. To rescale
the color to the usual range, this formula can be used:

```hlsl
float3 scaled_col = (GetBlur1(uv) - blur1_min) * (1.0 / (blur1_max - blur1_min));
```

Should each blur level use a different clipping range, this formula should use the _lowest_ maximum and _highest_
minimum of all levels used for the sampled texture.

### Edge Darkening

In the first blur level, an additional edge darkening effect can be applied. This will fade out color brightness around
the image border to prevent artifacts like color bleeding.

The edge thickness is a fixed percentage of the image size and the darkening value only affects the alpha value of this
"border".

### Use Cases

These blurred variants are useful in shaders to create some of the most appealing visual effects like clouds, water and
ripples. Another use case would be creating glow or bloom effects and even "god rays" emanating from bright spots in the
image when using color clipping as described above.

### Caveats

When using a blur texture in any shader, be aware that the blur texture will not contain any drawn effects like waves
and shapes _before warping_.

This has a few implications:

- When using blur textures in the Warp shader, the Motion Vectors in that image will be one frame old, while shapes and
  waves will already be _two frames_ old.
- When using blur textures in the Composite shader, the Motion Vectors in that image will be from the current frame,
  while shapes and waves will already be _one frames_ old.

## Default Settings

The following setting keys configure the default values and initialize expression variables for the Default Waveform
effect:

| .milk Setting Key | Type  | Range  | Description                                       |
|-------------------|-------|--------|---------------------------------------------------|
| `b1n`             | FLOAT | 0 .. 1 | Minimum clipping value for the first blur level.  |
| `b2n`             | FLOAT | 0 .. 1 | Minimum clipping value for the second blur level. |
| `b3n`             | FLOAT | 0 .. 1 | Minimum clipping value for the third blur level.  |
| `b1x`             | FLOAT | 0 .. 1 | Maximum clipping value for the first blur level.  |
| `b2x`             | FLOAT | 0 .. 1 | Maximum clipping value for the second blur level. |
| `b3x`             | FLOAT | 0 .. 1 | Maximum clipping value for the third blur level.  |
| `b1ed`            | FLOAT | 0 .. 1 | Blur edge darkening factor.                       |

## Expression Code Usage

The Blur Textures effect can be controlled with Milkdrop expression code in the following code blocks, using the
variables in the table below:

- `per_frame_init_`
- `per_frame_`

| .milk Setting Key | Expression Variable | Writeable |
|-------------------|---------------------|-----------|
| `b1n`             | `blur1_min`         | YES       |
| `b2n`             | `blur2_min`         | YES       |
| `b3n`             | `blur3_min`         | YES       |
| `b1x`             | `blur1_max`         | YES       |
| `b2x`             | `blur2_max`         | YES       |
| `b3x`             | `blur3_max`         | YES       |
| `b1ed`            | `blur1_edge_darken` | YES       |
