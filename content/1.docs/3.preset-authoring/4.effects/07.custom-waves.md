Custom Waveforms can be used to visualize oscilloscope or spectrum data similar to
the [Default Waveform effect](default-waveform), or draw any other user-defined line shape. Up to four separate Custom
Waves can be configured, each having its own code and variables.

Each waveform is drawn as a line (or simple points), with up to 512 points, each of which can be positioned individually
via expression code. The color of each point can also be set to a different value, with the line connecting two points
smoothly interpolating the color as a gradient. This allows preset authors to draw basically any shape, even (fake) 3D
objects as shown in the screenshot above.

## Default Settings

In the preset file, Custom Waves are prefixed with `wavecode_N_`, where `N` is the index of the waveform from `0` to
`3`.

The following setting keys configure the default values and initialize expression variables for each Custom Waveform
index:

| .milk Setting Key       | Expression Variable | Type  | Range        | Description                                                                                                                                    |
|-------------------------|---------------------|-------|--------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| `wavecode_N_enabled`    |                     | BOOL  | 0 or 1       | If non-zero, the waveform is enabled and drawn                                                                                                 |
| `wavecode_N_samples`    | `samples`           | INT   | 0 .. 480/512 | The default number of samples (points) used to draw the waveform. The maximum is 480 for non-spectrum waveforms and 512 for spectrum waveforms |
| `wavecode_N_sep`        |                     | INT   | 0 .. 240/256 | Number of samples (points) between left and right channel data                                                                                 |
| `wavecode_N_bSpectrum`  |                     | BOOL  | 0 or 1       | If non-zero, the waveform will use spectrum data, otherwise oscilloscope (wave) data                                                           |
| `wavecode_N_bUseDots`   |                     | BOOL  | 0 or 1       | If non-zero, the waveform will be drawn as dots instead of a continuous line                                                                   |
| `wavecode_N_bDrawThick` |                     | BOOL  | 0 or 1       | If non-zero, the waveform will be drawn four times in a 2x2 pattern to increase visibility                                                     |
| `wavecode_N_bAdditive`  |                     | BOOL  | 0 or 1       | If non-zero, the waveform will add color to the existing image instead of replacing the existing color                                         |
| `wavecode_N_scaling`    |                     | FLOAT | any          | Multiplier to apply on the final spectrum or oscilloscope value (after smoothing) for each sample                                              |
| `wavecode_N_smoothing`  |                     | FLOAT | 0.0 .. 1.0   | The smoothing amount for the waveform. 0=no smoothing, 1=heavy smooting                                                                        |
| `wavecode_N_r`          | `r`                 | FLOAT | 0.0 .. 1.0   | Default amount of red color of the waveform                                                                                                    |
| `wavecode_N_g`          | `g`                 | FLOAT | 0.0 .. 1.0   | Default amount of green color of the waveform                                                                                                  |
| `wavecode_N_b`          | `b`                 | FLOAT | 0.0 .. 1.0   | Default amount of blue color of the waveform                                                                                                   |
| `wavecode_N_a`          | `a`                 | FLOAT | 0.0 .. 1.0   | Default opacity of the waveform. 0=transparent, 1=opaque                                                                                       |

## Expression Code Usage

For each of the four Custom Waveforms, there is one initialization code block, executed once when the preset is loaded,
a `per_frame` block, which is actually executed once per rendered frame and finally a `per_point` code block, which is
executed for each individual waveform point/vertex after the waveform's `per_frame` code block has finished.

These code blocks have a different prefix than the settings above:

- `wave_N_init`
- `wave_N_per_frame`
- `wave_N_per_point`

The line number is immediately appended to these prefixes, without an additional underscore, like this:
`wave_0_per_frame1`

The following waveform-specific variables are available in all three waveform-specific code blocks, except `samples`,
which is not available in the `wave_N_per_point` block:

| Expression Variable | Writeable | Description                                                                                                                                                                           |
|---------------------|-----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `r`                 | YES       | Amount of red color of the waveform                                                                                                                                                   |
| `g`                 | YES       | Amount of green color of the waveform                                                                                                                                                 |
| `b`                 | YES       | Amount of blue color of the waveform                                                                                                                                                  |
| `a`                 | YES       | Opacity of the waveform. 0=transparent, 1=opaque                                                                                                                                      |
| `samples`           | YES       | The number of samples used to draw the waveform. Can be changed in each invocation of the `wave_N_per_frame` block.                                                                   |
| `time`              | NO        | The current time, in seconds, since the application was started                                                                                                                       |
| `fps`               | NO        | The current framerate, in frames per second                                                                                                                                           |
| `frame`             | NO        | The number of frames of animation elapsed since the program started                                                                                                                   |
| `progress`          | NO        | Progress through the current preset; if preset was just loaded, this is closer to 0; if preset is about to end, this is closer to 1. If the preset is locked, this value will freeze. |
| `bass`              | NO        | The current amount of bass.  1 is normal; below ~0.7 is quiet; above ~1.3 is loud bass                                                                                                |
| `mid`               | NO        | Same as `bass`, but for mids (middle) frequencies                                                                                                                                     |
| `treb`              | NO        | Same as `bass`, but for treble (high) frequencies                                                                                                                                     |
| `bass_att`          | NO        | An attenuated/smoothed reading on the bass, meaning that it is damped in time and doesn't change so rapidly.                                                                          |
| `mid_att`           | NO        | An attenuated/smoothed reading on the mids, meaning that it is damped in time and doesn't change so rapidly.                                                                          |
| `treb_att`          | NO        | An attenuated/smoothed reading on the treble, meaning that it is damped in time and doesn't change so rapidly.                                                                        |
| `q1` .. `q32`       | YES       | 32 `q` variables. See notes below for a detailed explanation on value propagation.                                                                                                    |
| `t1` .. `t8`        | YES       | 8 `t` variables specific to each Custom Waveform. See notes below for a detailed explanation on value propagation.                                                                    |

In each `wave_N_per_point` block, these additional variables are available for use in expressions:

| Expression Variable | Writeable | Description                                                                                                                 |
|---------------------|-----------|-----------------------------------------------------------------------------------------------------------------------------|
| `x`                 | YES       | The x position of this point that makes up the wave. 0=left, 1=right                                                        |
| `y`                 | YES       | The y position of this point that makes up the wave. 0=bottom, 1=top                                                        |
| `sample`            | NO        | How far along we are, through the samples that make up the waveform: 0=first sample, 0.5 = half-way through; 1=last sample. |
| `value1`            | NO        | The value of the left audio channel sample at this point in the waveform (or frequency spectrum).                           |
| `value2`            | NO        | The value of the right audio channel sample at this point in the waveform (or frequency spectrum).                          |

### Notes

- The waveform is only drawn if the number of samples is at least 1 for dot waveforms or 2 for line waveforms. Setting
  samples to a value below these skips the rendering of the waveform, allowing to turn it on and off on demand.
- In line mode, the waveform is always drawn as a single, continuous line. Due to color interpolation, creating gaps
  requires at least three points, with the first and third at the same positions as the previous or next colored points,
  respectively.
- It is not possible to automatically connect the start and end points, so drawing loops must be done by manually
  placing the last point on top of the first.
- Since the `samples` variable is not available in the `wave_N_per_point` block, to calculate the point index the
  `samples` value must be passed via `q`, `t` or other global variables from the `wave_N_per_frame` block.

#### Q Variable Propagation

The 32 `q` variables are propagated like this:

- Once from the preset's `per_frame_init` code to each waveform's `wave_N_init` block.
- On each frame, the values are copied from the preset's `per_frame` code to each waveform's `wave_N_per_frame` block,
  then passed to `wave_N_per_point`.
  Each subsequent `wave_N_per_point` execution will retain the `q` var values from the previous point.

#### T Variable Propagation

The 8 `t` variables are propagated like this:

- On each frame, the `t` var values are copied from the `wave_N_init` state to each waveform's `wave_N_per_frame` block,
  then passed to `wave_N_per_point`. Each subsequent `wave_N_per_point` execution will retain the `t` var values from
  the previous point.
