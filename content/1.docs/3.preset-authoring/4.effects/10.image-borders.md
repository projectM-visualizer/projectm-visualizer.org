---
title: Image Borders
description: Draws a set of borders around the whole screen.
---

![Image Borders Effect](/content/preset-guide/effect-image-borders.png){style="width: 50%;"}

The Image Borders effect draws one or two colored borders around the whole drawing area. Each border, inner and outer,
can have separate thickness, color and alpha values.

If the sum of the thickness of both borders exceed 1, the inner border will "overdraw" to the outside again.

The Image Border effect thickness ratio between horizontal and vertical borders will match the aspect of the image,
e.g. in landscape images, the vertical border will appear wider than the horizontal ones. There is no option to make the
border always use the same thickness on all edges.

## Default Settings

| .milk Setting Key | Type  | Range  | Description                                                                                                                     |
|-------------------|-------|--------|---------------------------------------------------------------------------------------------------------------------------------|
| `ob_size`         | FLOAT | 0 .. 1 | Thickness of the outer border.<br>(0 = no border, 0.5 = covers half the distance from border to center, 1 = covers whole image) |
| `ob_r`            | FLOAT | 0 .. 1 | The amount of red in the outer border.                                                                                          |
| `ob_g`            | FLOAT | 0 .. 1 | The amount of green in the outer border.                                                                                        |
| `ob_b`            | FLOAT | 0 .. 1 | The amount of blue in the outer border.                                                                                         |
| `ob_a`            | FLOAT | 0 .. 1 | The opacity of the outer border.<br>(0 = fully transparent, 1 = fully opaque)                                                   |
| `ib_size`         | FLOAT | 0 .. 1 | Thickness of the inner border.<br>(0 = no border, 0.5 = covers half the distance from border to center, 1 = covers whole image) |
| `ib_r`            | FLOAT | 0 .. 1 | The amount of red in the inner border.                                                                                          |
| `ib_g`            | FLOAT | 0 .. 1 | The amount of green in the inner border.                                                                                        |
| `ib_b`            | FLOAT | 0 .. 1 | The amount of blue in the inner border.                                                                                         |
| `ib_a`            | FLOAT | 0 .. 1 | The opacity of the inner border.<br>(0 = fully transparent, 1 = fully opaque)                                                   |

## Expression Code Usage

All settings of the Image Bordes effect can be controlled using Milkdrop expression code in the following code blocks:

- `per_frame_init_`
- `per_frame_`

### Per-Frame Code

All the global default values as listed above can be used and changed in the `per_frame_init_` and `per_frame_`
blocks using the same variable names and can be changed/written to animate both borders.

| .milk Setting Key | Expression Variable | Writeable |
|-------------------|---------------------|-----------|
| `ob_size`         | `ob_size`           | YES       |
| `ob_r`            | `ob_r`              | YES       |
| `ob_g`            | `ob_g`              | YES       |
| `ob_b`            | `ob_b`              | YES       |
| `ob_a`            | `ob_a`              | YES       |
| `ib_size`         | `ib_size`           | YES       |
| `ib_r`            | `ib_r`              | YES       |
| `ib_g`            | `ib_g`              | YES       |
| `ib_b`            | `ib_b`              | YES       |
| `ib_a`            | `ib_a`              | YES       |
