---
title: Non-Shader Post-Processing Filters
description: Apply classic non-shader filters on the image before being displayed to the user.
---

::note  
**Important**: All effects described here will only be applied if `MILKDROP_PRESET_VERSION` is below 200 _or_ the
`PSVERSION` (preset version 200) or `PSVERSION_COMP` (preset version 201) value is set to 0! Any other value uses a
composite shader, either the preset's own or one generated by Milkdrop (see the end of this page).  
::

The post-processing filters are applied in the order listed, if more than one is active.

All post-processing effects are only applied to the on-screen image, and are _not_ passed to the next frame, e.g. they
are not being drawn to "main" texture as all previously documented effects.

## Video Echo

![Video Echo Effect](/content/preset-guide/effect-video-echo.png){style="width: 50%;"}

Draws an "echo" (or ghost image) of the original image over the screen. The image can also be zoomed in or out to create
smaller or larger versions of the original image.

When scaling the image down, the space between the smaller image and the screen borders will be filled by repeating the
outermost pixels of the zoomed image, creating a bar-like effect as seen in the example image above (using 0.5 zoom
factor, 0.5 alpha value and flipped on the Y axis with orientation mode 2).

::note  
If the Video Echo effect is enabled (alpha > 0.001), the separate [Gamma Adjustment](#gamma-adjustment)
drawing branch is skipped. The gamma value still controls additive redraws of each echo layer.
::

### Default Settings

The following setting keys configure the default values and initialize expression variables for the Default Waveform
effect:

| .milk Setting Key       | Type  | Range   | Description                                                                                                                                  |
|-------------------------|-------|---------|----------------------------------------------------------------------------------------------------------------------------------------------|
| `fVideoEchoZoom`        | FLOAT | 0 .. 10 | Amount of zoom applied to the echoed image.<br>(0 = invisible, 1 = original size, 10 = 1000% zoom)                                           |
| `fVideoEchoAlpha`       | FLOAT | 0 .. 1  | The opacity of the echo effect.<br>(0 = invisible/disabled, 0.5 = 50% blend, 1 = only echo image)                                            |
| `nVideoEchoOrientation` | INT   | 0 to 3  | Controls the orientation of the echo image. Value wraps with modulo 4.<br>(0 = original orientation, 1 = flip X, 2 = flip Y, 3 = flip X & Y) |

### Expression Code Usage

Original MilkDrop exposes `echo_zoom`, `echo_alpha` and `echo_orient` in per-frame expression code.

## Gamma Adjustment

![Gamma Adjustment Effect](/content/preset-guide/effect-gamma-adjustment.png){style="width: 50%;"}

Allows to adjust the image gamma brightness by the given factor.

::note  
If the [Video Echo](#video-echo) effect is enabled (alpha > 0.001), its drawing branch applies the gamma
value through additive redraws. The separate gamma-only drawing branch is skipped.
::

### Default Settings

The following setting keys configure the default values and initialize expression variables for the Default Waveform
effect:

| .milk Setting Key | Type  | Range   | Description                                                                                                 |
|-------------------|-------|---------|-------------------------------------------------------------------------------------------------------------|
| `fGammaAdj`       | FLOAT | 0 .. 10 | The amount of gamma adjustment applied.<br>(0.5 = half brightness, 1 = no change, 2 = twice as bright, ...) |

### Expression Code Usage

Original MilkDrop exposes `gamma` in per-frame expression code.

## Brighten Image

![Brighten Image Effect](/content/preset-guide/effect-brighten.png){style="width: 50%;"}

Applies a non-linear brightening filter by inverting the image, squaring it, then inverting it again.
For an unquantized colour component `c`, the result is `1 - (1 - c)^2`, or `2*c - c*c`.
For example, `c = 0.25` becomes `0.4375`; this is not the literal mathematical square root.
Native framebuffer storage may quantize between the three passes.

### Default Settings

The following setting keys configure the default values and initialize expression variables for the Default Waveform
effect:

| .milk Setting Key | Type | Range  | Description                                    |
|-------------------|------|--------|------------------------------------------------|
| `bBrighten`       | BOOL | 0 or 1 | Enables or disables the Brighten Image effect. |

### Expression Code Usage

Original MilkDrop exposes `brighten` in per-frame expression code.

## Darken Image

![Darken Image Effect](/content/preset-guide/effect-darken.png){style="width: 50%;"}

Applies a non-linear darkening filter by multiplying the image with itself. For a colour component `c`, the result is
`c * c`, so darker parts lose more of their brightness than bright parts.

### Default Settings

The following setting keys configure the default values and initialize expression variables for the Default Waveform
effect:

| .milk Setting Key | Type | Range  | Description                                  |
|-------------------|------|--------|----------------------------------------------|
| `bDarken`         | BOOL | 0 or 1 | Enables or disables the Darken Image effect. |

### Expression Code Usage

Original MilkDrop exposes `darken` in per-frame expression code.

## Solarize Image

![Solarize Image Effect](/content/preset-guide/effect-solarize.png){style="width: 50%;"}

Emphasizes mid-range colors and darkens both very dark and very bright parts. The two blend passes compute
`2 * c * (1 - c)` for a colour component `c`: a value of 0.5 becomes 0.5, while 0 and 1 both become 0.

### Default Settings

The following setting keys configure the default values and initialize expression variables for the Default Waveform
effect:

| .milk Setting Key | Type | Range  | Description                                    |
|-------------------|------|--------|------------------------------------------------|
| `bSolarize`       | BOOL | 0 or 1 | Enables or disables the Solarize Image effect. |

### Expression Code Usage

Original MilkDrop exposes `solarize` in per-frame expression code.

## Invert Image

![Invert Image Effect](/content/preset-guide/effect-invert.png){style="width: 50%;"}

Inverts the colors in the image. Each colour component `c` becomes `1 - c`.

## Implementation and reference notes

The expression controls above describe the original MilkDrop renderer. Some projectM versions read file defaults for
these effects instead of the evaluated per-frame variables; check the implementation and version when relying on dynamic
control. A custom composite shader still replaces this legacy path.

::note
**Generated composite shaders**: If a preset has a composite shader version above 0 but no `comp_` code, Milkdrop
generates a composite shader from the preset's settings instead of using the filters described on this page. This
generated shader uses different math: Brighten is `sqrt(c)`, Darken is `c * c`, Solarize is `4 * c * (1 - c)` and Invert
is `1 - c`. It is built once when the preset loads, so it uses the values from the preset file and ignores changes made
to `brighten`, `darken`, `solarize`, `invert`, `gamma` and the echo variables in per-frame code. See the
[Rendering Process](../preset-rendering-process) page for details.
::

These details come from the original
[MilkDrop2 rendering source](https://github.com/projectM-visualizer/milkdrop2/blob/f05b0d811a87a17c4624170c26c93bac39b05bde/src/vis_milk2/milkdropfs.cpp):
the evaluated echo/gamma inputs begin around line 4147, gamma-controlled redraws occur inside the echo branch around line
4218, and the filter blend passes begin around line 4282. The source comment calls Brighten a square-root filter; the
actual blend operations implement the polynomial above. The generated composite shader is written by
`CPlugin::GenCompPShaderText` in `plugin.cpp`.
