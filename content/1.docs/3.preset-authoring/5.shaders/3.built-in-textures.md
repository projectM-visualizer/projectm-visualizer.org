title: Built-In Textures
description: Using the main, blur and noise textures provided by Milkdrop.
---

Besides [external images](user-textures), Milkdrop provides a set of built-in textures to every shader. Like any other
texture, they are used by declaring a sampler with the texture's name and the `sampler_` prefix:

```hlsl
sampler sampler_noise_lq;

shader_body {
    ret = tex2D(sampler_noise_lq, uv * 4).xyz;
}
```

The main and blur textures can also be used through the helper functions `GetMain()`, `GetPixel()` and `GetBlur1()` to
`GetBlur3()`, which need no declaration.

## Filtering and Wrapping

The sampler name can contain a two-letter prefix after `sampler_` which selects how the texture is sampled:

| Prefix          | Filtering           | Coordinates outside of `[0..1]` |
|-----------------|---------------------|---------------------------------|
| `fw_` or `wf_`  | Bilinear            | Wrap (repeat)                   |
| `fc_` or `cf_`  | Bilinear            | Clamp to edge                   |
| `pw_` or `wp_`  | Point (pixel-exact) | Wrap (repeat)                   |
| `pc_` or `cp_`  | Point (pixel-exact) | Clamp to edge                   |

The prefix is case-insensitive. Without a prefix, textures are sampled with bilinear filtering and wrapping, except the
blur textures, which default to bilinear filtering and clamping.

For example, `sampler_pc_main` reads the main texture pixel-exact and clamped, which is useful when the image is used to
store data in its color channels rather than to display it.

::note
Milkdrop removes _any_ two letters followed by an underscore from the start of the name, even if they are not one of the
prefixes above. A texture file named `ab_stars.jpg` referenced as `sampler_ab_stars` is therefore looked up as `stars`.
Avoid texture names with an underscore as the third character.
::

HLSL `sampler_state` blocks, which are normally used to set filtering and wrapping in HLSL, are not evaluated by
Milkdrop or projectM. Only the name prefix selects the sampling mode.

## Main Texture

`sampler_main` samples the main preset image:

- In the warp shader, it contains the previous frame. Sampling it at the warped `uv` coordinate is what moves the image
  from frame to frame.
- In the composite shader, it contains the current frame after all effects have been drawn, but before post-processing.

The helper functions `GetMain(uv)` and `GetPixel(uv)` sample this texture with the default settings.

In Milkdrop, the warp shader's `sampler_main` uses the sampler prefix only. The `wrap` preset setting is applied to the
built-in (non-shader) warp effect, not to custom warp shaders.

## Blur Textures

The [Blur Textures effect](../effects/blur-textures) creates up to three blurred, downscaled copies of the main image:

| Sampler         | Size                 | Helper function |
|-----------------|----------------------|-----------------|
| `sampler_blur1` | 1/4 of the main image | `GetBlur1(uv)` |
| `sampler_blur2` | 1/8 of the main image | `GetBlur2(uv)` |
| `sampler_blur3` | 1/16 of the main image | `GetBlur3(uv)` |

To improve color precision, each blur level stores its colors scaled to the level's own range, from `blurN_min` to
`blurN_max`. Sampling `sampler_blur1` directly therefore returns a value in the scaled range, not the original color.
The helper functions undo the scaling:

```hlsl
// GetBlur1(uv) is equivalent to:
float3 c = tex2D(sampler_blur1, uv).xyz * (blur1_max - blur1_min) + blur1_min;
```

Use the `GetBlurN()` functions unless the scaled value is exactly what is needed. Milkdrop only renders the blur levels
a shader actually uses: if a shader calls `GetBlur2()`, levels 1 and 2 are updated, but not level 3.

## Noise Textures

Milkdrop generates six noise textures when it starts. They contain random RGBA values; the larger textures are smoothed
so that neighboring texels change gradually:

| Name            | Dimensions | Size         | Smoothing                         |
|-----------------|------------|--------------|-----------------------------------|
| `noise_lq`      | 2D         | 256 × 256    | None, every texel is random       |
| `noise_lq_lite` | 2D         | 32 × 32      | None                              |
| `noise_mq`      | 2D         | 256 × 256    | Smoothed over 4 texels            |
| `noise_hq`      | 2D         | 256 × 256    | Smoothed over 8 texels            |
| `noisevol_lq`   | 3D         | 32 × 32 × 32 | None                              |
| `noisevol_hq`   | 3D         | 32 × 32 × 32 | Smoothed over 4 texels            |

3D noise is sampled with `tex3D` and a `float3` coordinate. A common technique is to move through the volume over time,
or rotate the lookup coordinate with one of the random [rotation matrices](inputs):

```hlsl
sampler sampler_noisevol_hq;

shader_body {
    float3 n = tex3D(sampler_noisevol_hq, float3(uv * 2, time * 0.05)).xyz;
    ret = GetMain(uv + (n.xy - 0.5) * 0.01);
}
```

The noise values are generated randomly each time Milkdrop or projectM starts, so a preset must not rely on a specific
noise pattern.

The size of each noise texture can be read in the shader through `texsize_<name>`, e.g. `texsize_noise_lq`, like for any
other texture.
